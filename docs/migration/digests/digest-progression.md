# Digest: docs/llm/progression/ (95 tickets, spec, proposals, drafts)

Read-only digest for the fresh project. Vocabulary follows GLOSSARY.md. Source tags: (Qnnn) = designer answer; (designer, date; ticket progression/NN). "Built defaults" are what an agent built and the designer did not change; they hold unless a later answer says otherwise. Later date wins when answers conflict; reversals are named inline. Current state of the campaign in short: the game starts with a working washing machine and a full Laundry bin; the first wash breaks it and spits out the Socks; each floor's Stage (fill every Drawer of the unlocked Cabinets) makes a Part pop out; carrying the Part to the machine opens the next floor; the Old Tree (Upgrade station) gives a present per completed Collection; the ending is loading three prefilled bins into the machine after the last Fix, then the final screen.
